# 백현 행정사사무소 홈페이지 데모 3 (데모 2 + 3D 책상 첫 화면)

데모 2와 같은 사이트에 첫 화면만 실시간 3D 책상 장면(Three.js)으로 바꿨습니다.
- PC: 마우스를 따라 시점이 움직이고, 물건에 올리면 살짝 들립니다. 도장을 누르면 서류에 찍히고, 스탠드를 누르면 불이 꺼졌다 켜집니다. 서류철은 열리고, 펜과 머그는 돌아갑니다.
- 휴대폰과 3D를 못 쓰는 브라우저: 3D 파일(약 530KB)을 아예 불러오지 않고 같은 장면의 사진(`assets/hero-mobile.jpg`, 70KB)을 띄웁니다. 광고 첫 화면이 빨리 뜨게 하려는 것입니다.
- 3D 장면 원본: `src/hero3d.src.js`. 고친 뒤 `npx esbuild demo3/src/hero3d.src.js --bundle --minify --format=iife --outfile=demo3/assets/hero3d.js`로 다시 만듭니다 (three@0.170 필요).
- 대체 사진은 `index.html?poster=d`(PC), `?poster=m`(휴대폰)으로 연 화면을 찍은 것입니다.


`index.html`을 더블클릭하면 열립니다. 인터넷이 연결되어 있어야 글꼴이 제대로 보입니다.

## 페이지 (데모 3 구성)
- `index.html` 대문: 3D 첫 화면, 주요 실적(데모용 예시 사례, 가린 서류 사진 자리), 명함형 사무소 정보
- 메뉴 페이지: `work.html` 업무분야·FAQ, `about.html` 행정사 소개, `process.html` 진행절차, `contact.html` 오시는 길

## 페이지 (데모 2에서 이어짐)
- `index.html` 메인 (네이버 광고로 들어올 첫 화면)
- `board.html` 업무 일지 목록, `post.html` 글 보기
- `admin.html` 관리자 (데모 비밀번호 `1234`)
  - 게시글: 쓰기, 수정, 삭제
  - 사이트 문구: 첫 화면 제목·설명, 전화, 주소, 운영시간, 대표 소개를 직접 수정
  - 블로그 연동: 네이버 블로그 글을 업무 일지로 가져오기 (데모는 예시 2개)

데모라서 모든 내용은 이 브라우저(localStorage)에만 저장됩니다.
실제 서비스에서는 서버가 블로그 RSS(rss.blog.naver.com/baek-haeng.xml)를 주기적으로 읽어 자동으로 올립니다.
홈페이지 → 블로그 방향은 네이버가 글쓰기 API를 닫아서 지원하지 않습니다.

## 참고한 사이트
세움(실무 기록 컨셉), 한솔(손그림 선 일러스트), 태송·한양(실제 사진 자리), 티움(글 위주 배치)

## 교체할 곳
`[교체]` 주석: 전화번호, 사진, 주소, 지도, 사업자 정보. 사진은 `.slot` 자리에 `<img>`를 넣으면 됩니다.
